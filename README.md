画面分三块，背景为黑。灰度值：

- 上面 70 行是价格。收盘高于开盘的实体为 255，收盘低于或等于开盘的实体为 96。开盘到收盘的实体涂满这 3 列。最低到最高的影线只画在中间列，灰度为 176。没有均线。
- 中间 15 行是成交量，只画中间列。阳线对应 220，阴线对应 48，和实体的灰度不同。
- 下面 15 行是 MACD。EMA 12/26，信号线 9。计算时带上窗口之前最多 105 根收盘做预热，只把窗口内这一段画出来。DIF 为 200，只落在每根 K 线的左列。DEA 为 140，只落在右列。柱画在中间列，大于等于 0 为 255，小于 0 为 64。顶点不连成横穿其他列的线，避免盖住柱。DIF、DEA 和柱一起按窗口内最大绝对值缩放到这 15 行里。

价格先把窗口第一根收盘当作锚，在收益率路径上重建 OHLC，再用窗口内 OHLC 的最小最大值归一化。MACD 用同一条收益率路径，锚点收盘为 1。样本是每个交易日一张图。

生成在 `03_generate_images.ipynb`。`WINDOW_KEY` 用 `20` 或 `60`。当前默认 `MAX_CODES = None` 生成全量；调试时可改成 `20`，调试完成后须重新生成全量再训练。

## 标签与样本过滤

`labels.parquet` 的列：

| 列 | 含义 |
|---|---|
| `code`、`date` | 股票和调仓日 t |
| `stock_ret` | t 之后 5 个交易日的个股收益，`prod(1+r)-1` |
| `mkt_ret` | 同期 688 平权的 5 日收益。日收益来自 `pingquan.csv` 的 `688` 列，单位由百分数换成小数 |
| `future_ret` | `stock_ret - mkt_ret`，回归的目标 |
| `label` | `future_ret > 0` 为 1，否则为 0。本仓库训练时不使用这一列 |
| `split` | `train`、`valid`、`test` 或 `ignore` |

过滤与 `no_rolling` 相同，在生成图像时完成：

- 只保留 `universe.parquet` 里 `eligible` 的股票。
- 窗口在 t 之前必须凑满，t 之后必须还有 5 个交易日。
- 上市缓冲 1 根：窗口起点不能落在该股票行情的第一根上。
- 调仓日 t 涨停或跌停的样本去掉。窗口内部的涨跌停保留，也不要求 t+1 非涨停。
- 从窗口第一天到 t+5，只要有一天 ST，整段去掉。
- 这段日期在全市场日历上的跨度大于 `窗口 + 5` 时，视为中间有停牌，去掉。
- 窗口内成交量，以及 t+1 到 t+5 的个股收益和 688 收益，都必须是有限数。

划分按时间，训练和验证之间、验证和测试之间各空出 `窗口` 个交易日，避免同一段 K 线同时出现在两个集合里：

- 2015-01-01 到 2019-12-31 为训练加验证，按日期取前 70% 做训练。
- 空出窗口长度后再做验证。
- 再空出同样长度，并且不早于 2020-01-01，直到 2025-12-31 为测试。
- 落在两段空档里的样本标记为 `ignore`。图像仍在 `images.npy` 里，训练和预测都不读它们。

## 模型

每块仍为无偏置卷积、BatchNorm、LeakyReLU（负斜率 0.01）和 MaxPool。仅 I20 扩大时间方向的卷积采样间隔，I60 保留原四层结构。参数按“高、宽”排列。

| 参数 | 第四轮分层卷积 I20 | 第五轮时域扩张 I20 | I60（保留） |
|---|---|---|---|
| 输入 | `(1,100,60)` | 相同 | `(1,100,180)` |
| 通道 | 64, 128, 256 | 相同 | 64, 128, 256, 512 |
| 每层卷积核 | `(5,3)` | 相同 | `(5,3)` |
| 三层扩张率 | `(1,1)、(1,1)、(1,1)` | `(1,1)、(1,3)、(1,6)` | 四层均 `(1,1)` |
| 卷积步长 | `(1,1)、(2,1)、(2,1)` | 相同 | 四层均 `(3,1)` |
| 卷积填充 | 三层均 `(2,1)` | `(2,1)、(2,3)、(2,6)` | 四层均 `(12,1)` |
| 池化核 / 步长 | `(2,1) / (2,1)` | 相同 | 相同 |
| 池化后尺寸 | `50×60 → 12×60 → 3×60` | 相同 | `20×180 → 7×180 → 4×180 → 4×180` |
| 三层卷积局部时间范围 | 3 → 5 → 7 列 | 3 → 9 → 21 列 | 本轮不调整 |

dilation 改变卷积核采样点之间的间隔，卷积权重数量仍由 5×3 的核决定，形状计算使用有效核宽 `dilation × (kernel_width - 1) + 1`。实现依据 [PyTorch Conv2d 文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.Conv2d.html)。

第一层继续提取相邻列细节，第二层以 3 列（1 个交易日的像素宽度）为采样间隔，第三层以 6 列为间隔。三层组合的理论局部输入偏移连续覆盖 -10 到 +10，共 21 列，跨度相当于 7 根 K 线的像素宽度；具体涉及几根 K 线取决于列对齐和边界。本轮汇总结果支持继续研究较长跨度的局部特征组合，但具体收益机制和稳健性仍需验证。

这里的范围指注意力前卷积特征的局部理论感受野。原模型的展平线性层和时间注意力已经使用整张 20 日图片，不能说原模型只看两三天。本轮所有采样点都位于现有截至样本日的历史图像内或零填充区域，不增加未来行情。

卷积之后的时间注意力、展平、Dropout 0.5、线性层输出和初始化方式均保留。按配置计算，第四轮与第五轮 I20 均为 **663,106** 个可训练参数、**46,080** 个展平特征，每样本理论卷积乘加量均为 **367,027,200**。输出激活形状一致，但不同 dilation 可能改变 GPU 内核效率和工作区占用。本轮日志记录的三个种子累计训练耗时约 10.81 小时；未取得与第四轮相同环境下的耗时和显存对照。

训练目标仍为训练集截尾标准化目标上的纯 MSE，随机打乱全部训练样本。排序损失实现保留但关闭，不增加其他损失或取样改动。

`cnn.model_spec` 统一解析每层 kernel、stride、padding、dilation 并计算实际尺寸。扩张率默认值为 1，支持共用参数或按 I20 / I60 配置。模型结构标识更新为 `price_image_cnn_layerwise_dilated_v1`；既有 train_lib 无需修改，保存和加载时的结构校验会包含完整逐层扩张率。旧权重即使张量形状相同也不能混用，复现旧实验使用对应提交的整套代码。

## 训练

在 `04_train_predict.ipynb` 里运行。优化器是 Adam，学习率固定 `1e-5`，没有学习率衰减，也没有早停。每个种子固定 10 个 epoch。主权重留下验证集日均 Rank IC 最高的一轮：每天对预测值与未截尾 `future_ret` 计算 Spearman，再对有效日期等权平均。并列值使用平均秩；少于 3 只股票或分数/目标为常量的日期不计入，并记录有效日期数。没有有效日期时明确报错，不静默改用最后一轮。

同一训练过程还保留原整体 Spearman 指标最高的一轮，只增加指标计算和权重保存，不额外训练一遍。原整体指标的双 argsort 实现保持不变，以复现上一轮选模方式；新日内指标使用标准平均秩。两套候选都只使用验证集，测试集不参与选模。

训练集仍使用全部原本可训练的 `split == train` 样本，不做类别或收益下采样。像素均值和标准差在训练索引上抽 2 万张图估计，是一个标量。I20 的训练 batch 是 64，I60 是 32；`num_workers=0`，`pin_memory=False`。

本轮使用原随机 DataLoader：`shuffle=True`，保留末尾不足一批的样本。排序损失与同日分组取样关闭。实际耗时和显存使用量须由公司平台观察。

每轮仍打印训练/验证 mse、方向正确率、`pooled_ic`、`daily_ic`、有效日期数和 `epoch_s`。`daily_ic` 决定主模型。`loss_z` 为标准化目标上的 MSE，沿用的 `rank`、`pairs` 和有效 `rank_batches` 计数为零。权重保留完整 history、主/对照选模指标、最佳轮次、损失及取样配置，并增加实际逐层 `model_spec`。验证不建梯度图。

固定 `N_SEEDS=3`，随机种子为 `20260417`、`20260418`、`20260419`，每种子固定 10 轮。只有主/对照权重都完整，且模型结构、损失/取样、训练 batch、选模规则、种子和轮数匹配时才跳过已有种子。预测同样检查结构、损失/取样、选模规则、种子和轮数。缺少结构记录的旧版权重会报错；复现旧实验须使用对应版本的整套代码和配置。

每轮 `seed_k.running.pt` 保存当时主指标最好的权重，仍不支持断点续训；中断后该种子从头开始。对照最终权重先保存，再保存主最终权重；完成后删除 running 文件。

## 预测与回测

`predict_window` 只对 `test` 做推理，写出

```text
/storage/server/144server/cq/ChenSiwei/k_pictures_gray_body_i20_temporal_dilation_v1/results/pred_{I20|I60}.parquet
```

`pred` 是预测的 5 日超额，可以是负数。它和二分类版本的 `prob` 不是同一个量。`prob` 是“超额大于 0”的概率，范围在 0 到 1。两边选股时都是当天分数从高到低取前 10%。

默认预测恰好读取三个主权重，不递归扫描对照子目录。可用 `predict_window(..., selection="pooled_spearman")` 对三个旧规则候选做额外推理，结果单独写为 `pred_I20_pooled_spearman.parquet`，不覆盖主预测。该选项只增加推理，不增加训练；05 默认仍使用主结果。该对照同样来自本轮时域扩张模型的 MSE 训练，只改变选模规则；不能当作第四轮分层卷积权重。对照供报告使用，不能根据测试结果反向选择规则。

样本外还会打印 mse、方向正确率和 `pred` 与 `future_ret` 的相关系数。

`05_plot_top10.ipynb` 的回测与 `no_rolling` 的 5 个组合相同：

- 每个交易日按 `pred` 取最高 10%，等权。
- t 收盘买入，t+5 收盘卖出。资金分成 5 批，卖出所得再投入当天的新篮子，各批净值独立复利。
- 组合超额是当天各批超额相对 688 平权的净值加权平均。不满 5 批的日期不计入。
- 十分位、随机 10 组使用同一套盯市。
- 成本图按每边 5 个基点，在换仓时按单边换手的两倍扣除。十分位图本身不扣费。

## 信息边界

本轮结构只处理原有历史图像，没有新增未来输入、标签输入或跨样本时间信息。截尾和标准化只使用训练集，验证集用于选轮次；五日监督标签、数据划分及交易日隔离沿用原代码。已查看的 2020–2025 测试结果会影响研究方向，因此后续在同一区间的改善只能作为迭代证据，不能当作全新未见数据上的独立验证。

这不等于整个原框架通过了无前视审计：原持有期 ST/停牌筛选、未来收益缺失样本过滤及 t 日完整图片配合 t 收盘成交的时点问题按用户要求保留，详见操作记录第 7 节。

2. 重启内核，运行 `04_train_predict.ipynb`：确认 `loss=mse`、`sampler=random`、`select=daily_rank_ic`，`images` 指向 `k_pictures_gray_body_i20_attention_v1`，`output` 指向 `k_pictures_gray_body_i20_temporal_dilation_v1`。I20 打印的 `conv_dilation` 应为 `[[1,1],[1,3],[1,6]]`，`conv_padding` 为 `[[2,1],[2,3],[2,6]]`，`block_hw` 仍为 `[[50,60],[12,60],[3,60]]`。第一格会检查扩张率是否实际被 cnn.py 解析；不匹配时在训练前报错。训练完三个种子后运行预测格，确认写出 `pred_I20.parquet`。
3. `05_plot_top10.ipynb`：Top 10%、十分位、随机分组、扣费对照。

`WINDOW_KEY` 用 `"I20"` 或 `"I60"`，必须和已经生成的图一致。不要和正在读同一份 `images.npy` 的另一个训练同时跑，两边会抢网络盘。

主机内存约 62 GB，放不下整份 `images.npy`。训练使用内存映射，不要把整个数组读进内存。
