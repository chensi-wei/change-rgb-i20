## 结论与解释边界

1. 日均 Rank IC 与每日截面排序任务更一致，这轮 Top10% 的收益、图中夏普、胜率均小幅改善，值得保留作研究基线。十组年化超额严格单调，但这不等于每年、每天或所有种子均单调。
2. 原单种子含 MACD 结果为年化 15.77%、图中夏普 3.78476。本轮收益较高，夏普仍低 0.20311；跨结构和种子数的对比不能单独证明注意力或集成有效。
3. 本轮最高图中夏普出现在第 3 组（4.33358），不是第 0 组。全截面排序质量与 Top10% 的收益风险比并非同一目标；不能根据测试图事后改买第 3 组。
4. 图中累计超额使用日超额累加，最低组低于 -100% 不代表持仓净值为负。年化是日均超额乘 252，夏普由相对 688 的日超额均值/标准差计算，更接近信息比率，不是绝对收益的现金基准夏普。
5. 缺少逐日序列、换手、分年度、分种子和成本后结果，不能评估显著性、容量或实盘可行性。5 日持仓重叠也要求统计检验考虑序列相关，例如对成对日收益差用分块 bootstrap 或 HAC，而非独立样本检验。
6. 2020–2025 已被反复查看，应标记为被用于研究决策的历史评估期。后续模型选择仍只用训练/验证，最终结论需留出尚未查看的新时期或前向模拟。

## 下一版优先修改：候选池的时点

建议先固定含 MACD、时间注意力、三个种子、MSE、日均 Rank IC、学习率与轮数，单独检验候选池前视的影响。

- ST、历史涨跌停和停牌连续性仅检查到形成日 t，不以 t+1 到 t+5 状态删除 t 日股票。
- 标签按全市场交易日 t+1 到 t+5 对齐，不能放开停牌过滤后仍拿“该股接下来的五条记录”作为五天。
- 图像与预测候选资格不依赖未来标签是否完整；缺失标签保留缺失标记，训练/验证可排除无监督目标行，测试推理不能提前删掉它们。
- 新生成图像与标签、重新训练，使用新的独立目录，不读取旧候选池。

这一轮仅检验候选池问题。静态 `universe.parquet` 名单来源、完整 t 日数据配 t 收盘成交、持有期停牌/退市收益和可成交性仍需单独审计，不能宣称已完成无前视实盘回测。原回测把缺失日收益置零，该假设尤其不能自动用于退市和缺失数据。

如优先继续模型研究，下一项建议是固定其余条件，仅把 MSE 换为标准化目标上的 Huber（delta=1.0），作为预先固定的单因素实验；不同时更换注意力、图像或种子数，也不承诺会提高测试收益。
