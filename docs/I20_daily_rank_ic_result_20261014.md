## 结论与解释边界

1. 日均 Rank IC 与每日截面排序任务更一致，这轮 Top10% 的收益、图中夏普、胜率均小幅改善，值得保留作研究基线。十组年化超额严格单调，但这不等于每年、每天或所有种子均单调。
2. 原单种子含 MACD 结果为年化 15.77%、图中夏普 3.78476。本轮收益较高，夏普仍低 0.20311；跨结构和种子数的对比不能单独证明注意力或集成有效。
3. 本轮最高图中夏普出现在第 3 组（4.33358），不是第 0 组。全截面排序质量与 Top10% 的收益风险比并非同一目标；不能根据测试图事后改买第 3 组。
4. 图中累计超额使用日超额累加，最低组低于 -100% 不代表持仓净值为负。年化是日均超额乘 252，夏普由相对 688 的日超额均值/标准差计算，更接近信息比率，不是绝对收益的现金基准夏普。
5. 缺少逐日序列、换手、分年度、分种子和成本后结果，不能评估显著性、容量或实盘可行性。5 日持仓重叠也要求统计检验考虑序列相关，例如对成对日收益差用分块 bootstrap 或 HAC，而非独立样本检验。
6. 2020–2025 已被反复查看，应标记为被用于研究决策的历史评估期。后续模型选择仍只用训练/验证，最终结论需留出尚未查看的新时期或前向模拟。

## 下一版修改：沿用已确认的同日排序损失方案

当前会话已事先同意并在本地原项目中实现同日排序版；这张新图到来前就已固定参数，因此不根据本次测试结果再挑权重、阈值或组别。远程先保留本次已运行的纯 MSE + 日均 Rank IC 代码，本地排序版待公司平台运行。

| 项目 | 已运行的 Rank IC 版 | 下一版本地实现 |
|---|---|---|
| 损失 | 截尾标准化目标上的 MSE | MSE + 0.1 × 同日 RankNet |
| 取样 | 全样本随机 batch | 同日最多 16 行组成小组，混合小组后装入原 batch |
| 排序配对 | 无 | 只在训练集同日不同股票间，标准化目标差绝对值 > 0.1，每批最多 512 对 |
| 样本覆盖 | 每轮原可训练样本一次 | 相同；跳过排序配对不删除 MSE 样本 |
| 主选模 | 验证集日均 Rank IC | 相同，整体 Spearman 对照也保留 |
| 种子与轮数 | 3 个种子，每个 10 轮 | 相同 |
| 模型与图片 | 时间注意力 CNN、含 MACD 灰度图 | 相同，复用图片，不重跑 03 |
| 输出目录后缀 | `i20_attention_daily_ic_v1` | `i20_attention_rankloss_v1` |

排序项为 `softplus(-sign(z_i-z_j) * (s_i-s_j))` 的配对均值。它惩罚同日收益顺序排反；MSE 保留数值拟合约束。0.1 的目标差阈值使用训练集截尾标准化后的单位，不是原始收益率 10%。日期 ID 不传入 CNN。所有标准化统计与训练配对仅来自 train，验证/测试标签不参与更新参数。

下一版重点验证“训练目标与每日排序更一致是否有帮助”，不是断言本次图已证明 MSE 是瓶颈。排序约束并不直接优化 Top10% 夏普；同时改变取样顺序可能影响 BatchNorm，因此不能把差异完全归因于排序损失。每批复用一次前向、限制配对数，但实际耗时仍要由公司平台日志核验。

本地改动在原 `train_lib.py`、`config.yaml`、`04_train_predict.ipynb`；05 仅更新说明，执行代码不变。记录配对数、排序项、有配对批次数和每轮耗时，权重核对损失/取样配置以防混用。图片、筛选和回测保持用户既定规则。公司平台用另一份项目目录，重启内核后 04 → 05；权重和结果写到：
`/storage/server/144server/cq/ChenSiwei/k_pictures_gray_body_i20_attention_rankloss_v1`。

优先利用本次已经保存的 `pooled_spearman` 三个权重补一次对照推理（无需重训），核对同一训练轨迹的选模差异；它用于解释结果，不能按测试期优劣事后换选模规则。新一轮参数和主选模规则已预先固定。验证应同时看各个种子的验证表现与集成表现，评估期仍报告同一 Top10% 口径，不改买第 3 组。

## 原文其他备选与未解决的问题（本轮未采用）

以下为先前远程分析提出的候选池审计和 Huber 备选，保留作问题记录。用户此前明确要求不修改筛选规则，本次不将其作为已授权的下一版实现，也不自动替换已确认的排序损失方案。

建议先固定含 MACD、时间注意力、三个种子、MSE、日均 Rank IC、学习率与轮数，单独检验候选池前视的影响。

- ST、历史涨跌停和停牌连续性仅检查到形成日 t，不以 t+1 到 t+5 状态删除 t 日股票。
- 标签按全市场交易日 t+1 到 t+5 对齐，不能放开停牌过滤后仍拿“该股接下来的五条记录”作为五天。
- 图像与预测候选资格不依赖未来标签是否完整；缺失标签保留缺失标记，训练/验证可排除无监督目标行，测试推理不能提前删掉它们。
- 新生成图像与标签、重新训练，使用新的独立目录，不读取旧候选池。

这一轮仅检验候选池问题。静态 `universe.parquet` 名单来源、完整 t 日数据配 t 收盘成交、持有期停牌/退市收益和可成交性仍需单独审计，不能宣称已完成无前视实盘回测。原回测把缺失日收益置零，该假设尤其不能自动用于退市和缺失数据。

如优先继续模型研究，下一项建议是固定其余条件，仅把 MSE 换为标准化目标上的 Huber（delta=1.0），作为预先固定的单因素实验；不同时更换注意力、图像或种子数，也不承诺会提高测试收益。
